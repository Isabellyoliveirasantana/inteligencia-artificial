# Inteligência Artificial — Interface Interativa

Este repositório contém uma versão simples de um site que permite arrastar palavras para montar frases, visualizar e editar informações associadas a cada palavra.

O que eu adicionei/arrumei:
- index.html: nova página principal com área de banco de palavras, área de montagem (dropzone) e painel de informações.
- styles.css: estilos modernos e responsivos.
- script.js: lógica de arrastar/soltar, seleção de palavras, edição de informações e controles auxiliares.
- README.md: este arquivo explicando o projeto.

Como usar localmente:
1. Baixe/cloned o repositório.
2. Abra o arquivo `index.html` no seu navegador (ou sirva via `Live Server`/servidor simples).

Funcionalidades principais:
- Arrastar palavras do banco para a área de montagem e rearranjá-las.
- Ao clicar em uma palavra, seu card de informações aparece; é possível editar a palavra e suas informações.
- Botões para limpar a área de montagem e embaralhar o banco de palavras.
